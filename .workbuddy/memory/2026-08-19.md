## 自动更新修复 + MSI 命名统一
- MSI 命名统一为 `YangzaiWorkshop-windows-x64-v{Version}.msi`：build.ps1 的 msiPath/targetMsi/注释 + README 同步修改。此前 build.ps1 生成 `YangzaiWorkshop-v{x}.msi`，与 App.xaml.cs 自动拼接的下载地址 `YangzaiWorkshop-windows-x64-v{tag}.msi` 不一致。
- 修复自动更新「更新后还是老版本」的根因（App.xaml.cs InstallUpdate）：
  1. 批处理里 `INSTALL_FOLDER` 属性名错误 → 改为 `INSTALLFOLDER`（与 Product.wxs 的 Directory Id 一致），否则安装路径传不进去、装到默认位置，启动的仍是旧位置 exe。
  2. msiexec 结束后增加轮询等待（tasklist 检测 msiexec.exe 退出），避免 UAC 提权下包装进程提前返回、新版未写盘就启动旧 exe。
