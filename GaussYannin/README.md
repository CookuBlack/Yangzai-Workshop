# Gauss Yannin

一只置顶在桌面上的小羊宠物。它会扑腾、跑步、吃草、读书，可以跟随你的鼠标散步，也可以召集一群小羊伙伴陪你一起。内置番茄钟、整点报时、可自由排版的多窗口文字面板，并常驻系统托盘，随开机自启。

> 技术栈：C# / .NET 8 / WPF（透明置顶帧动画窗口）

---

## 功能总览

### 🐑 基础互动
- **单击**：点头
- **双击**：跳跃（抛物线弹跳）
- **左键拖拽**：把小羊抓到任意位置
- **滚轮**：直接在桌面上缩放宠物大小
- **右键**：呼出主菜单

### 🚶 行为模式（右键菜单）
| 模式 | 说明 |
| ------ | ------ |
| 散步 / 休息 | 同键切换。散步以「走路」开场，之后按 跑步 0.2 / 走步 0.5 / 休息 0.3 随机转换 |
| 跟随鼠标 | 离鼠标越远跑得越快（二次曲线速度），距离近则走路，贴近时休息 |
| 鼠标跟随 | 常驻置顶，透明区域自动点击穿透，可点边缘贴合小羊实际轮廓 |

### 🐑 羊群模式（右键 → 羊群模式，含二级菜单）
- **跟随**：小羊伙伴呈环形分布，跟随主羊移动，各自速度不同，互不重叠
- **散养**：小羊自由漫游，会散养吃草与奔跑
- 支持 1~50 只小羊（可在设置中调整数量）
- 召唤渐显、遣散渐隐

### ⏰ 番茄钟
- 二级菜单设置工作时长（15/30/45 分钟 / 自定义）与休息时长（5/10 分钟）
- 工作时小羊进入阅读状态，到点播放 `remind.mp3` 提醒
- 计时与提示共用一处气泡，先提示后计时

### 🕐 整点报时 & 时钟
- 整点报时：显示 `20:00` 样式，气泡至少保留 5 秒后渐隐
- 可在菜单中开关时间显示，支持 24 小时制 / 12 小时制、是否显示秒

### 📝 文字面板（右键 → 面板）
- 可打开多个面板窗口，依附主程序，不在任务栏显示
- 选中文字后右键：设置字号（10~36）、加粗、斜体、颜色、对齐
- 中键拖动窗口，右下角可调整大小，`Esc` 关闭

### 🖥 设置
- 宠物大小（100~360）
- 奔跑速度（2.5~8）
- 小羊数量（1~50）
- 时间显示：24/12 小时制、显示秒
- 番茄钟工作时长 / 休息时长
- 开机自启动
- 所有设置写入本地并持久化，重启自动恢复

### 🗔 系统托盘
- 常驻通知区域（隐藏图标），任务栏不显示单独窗口
- 托盘菜单：显示/隐藏宠物、设置、退出；双击托盘图标显示宠物

---

## 使用说明

1. 启动程序后，一只小羊出现在屏幕下方并挥手欢迎。
2. **单击 / 双击** 互动，**左键** 拖拽，**右键** 打开主菜单。
3. 在菜单中切换散步 / 跟随 / 羊群等模式，或进入设置调整参数。
4. 退出时在托盘菜单选择「退出」，小羊挥手后渐隐关闭（附随的面板窗口一并关闭）。

## 项目结构

| 文件 | 说明 |
| ------ | ------ |
| `MainWindow.xaml(.cs)` | 主羊：帧动画、行为引擎、透明点击穿透、托盘、菜单 |
| `SheepFollowerWindow.xaml(.cs)` | 小羊伙伴：跟随 / 散养、互斥避免重叠、渐显渐隐 |
| `NotePanelWindow.xaml(.cs)` | 文字面板：富文本排版、右键菜单、中键拖动 |
| `SettingsWindow.xaml(.cs)` | 设置界面：滑动条 + 手动输入、开机自启动 |
| `PetSettings.cs` | 设置的 JSON 持久化与自启动注册表管理 |
| `DurationInputDialog.xaml(.cs)` | 番茄钟自定义时长输入框 |
| `App.xaml(.cs)` | 入口 + 全局异常捕获（写入 crash.log） |
| `Assets/` | 各动作帧动画素材（Idle / Walk / Run / Wave / Nod / Jump / Reading / Grazing） |

## 数据与配置

- 设置文件：`%APPDATA%\DesktopPet\settings.json`（小羊可调参数的持久化）
- 设置日志：`%APPDATA%\DesktopPet\settings.log`（排查持久化问题）
- 崩溃日志：程序目录下 `crash.log`
- 自启动：写入注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`

## 运行环境

- Windows 10 / 11
- .NET 8 SDK（构建）/ .NET 8 运行时（运行）
